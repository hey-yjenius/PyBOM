# 데이터 준비 가이드

PyBOM은 Excel의 BOM, 재고, 수요를 연결해 구매·생산 판단에 필요한 정보를 보여줍니다.

먼저 [예제 Excel](https://github.com/hey-yjenius/PyBOM/releases/latest/download/PyBOM-Example.xlsx)을 열어 각 시트와 열의 설명을 확인하세요. 예제는 사용법을 보여주는 가상 자료이며 실제 발주에 사용하면 안 됩니다.

[영어 예제 Excel](https://github.com/hey-yjenius/PyBOM/releases/latest/download/PyBOM-Example-EN.xlsx)도 제공합니다. 안내문과 모든 열 메모를 영어로 읽을 수 있으며, 공급업체 이름은 실제 회사명 대신 `DEMO-SUPPLIER` 식별자를 사용합니다. 계산에 쓰이는 품번·수량·날짜는 한국어 예제와 같습니다.

## 처음 사용하는 순서

1. Windows ZIP을 전부 압축 해제하고 `PyBOM.exe`를 엽니다.
2. `Ctrl+O`로 예제 또는 자신의 Excel 파일을 선택합니다.
3. 시트 선택과 열 연결을 확인합니다.
4. 불러오기 요약에서 누락·제외·기본값 적용 경고를 읽습니다.
5. **Run all**로 분석하고, Dashboard에서 시작해 MRP와 Coverage를 확인합니다.

## 어떤 자료가 필요한가요?

BOM만으로 구조 분석을 시작할 수 있습니다. 실제 구매·생산 판단에는 재고와 날짜가 있는 수요도 함께 준비하세요.

| 시트 | 주요 열 | 용도 |
|---|---|---|
| BOM | `Parent`, `Child`, `Qty` | 상위 품목, 하위 부품, 상위 한 개당 소요량 |
| Master | `Item_Code`, `Description`, `Type`, `UOM`, `Lead_Time` | 품목 정보, 단위, 조달·제작 기간 |
| Inventory | `Item_Code`, `On_Hand`, `Allocated`, `On_Order`, `On_Order_Date` | 현재고, 배정량, 입고 예정 수량과 날짜 |
| Demand | `Item_Code`, `Qty`, `Due_Date` | 필요한 품목, 수량, 납기일 |
| Cost | `Item_Code`, `Unit_Cost` | 품목별 단가와 원가 분석 |
| Supplier | `Item_Code`, `Supplier_Code`, `Supplier_Name` | 품목별 공급업체 |
| Substitute | `Group_ID`, `Item_Code`, `Priority` | 승인된 대체품과 우선순위 |

표는 대표 항목 안내입니다. 자세한 선택 항목과 예시는 프로그램의 **Help > Field Guide**에서 오프라인으로 볼 수 있습니다.

## Excel 작성 원칙

- 첫 행에는 열 이름, 다음 행부터 자료를 넣습니다.
- 품번은 모든 시트에서 동일하게 사용합니다. 앞자리 0이 있는 품번은 문자로 보관합니다.
- 셀 병합을 피하고, 각 행의 품번을 빠짐없이 입력합니다.
- 수량과 단가는 숫자로 입력합니다. `2EA`처럼 단위를 값에 붙이지 않습니다.
- 날짜는 Excel 날짜 또는 `2026-11-10`처럼 일관된 형식으로 입력합니다.
- 서로 다른 단위를 섞지 않습니다. PyBOM은 단위 불일치를 알리지만 자동 환산하지 않습니다.
- 같은 자료를 중복으로 붙여 넣지 않습니다. 여러 입고 건은 각각의 수량과 날짜를 구분합니다.

## BOM 기준수량이 있는 경우

`Qty`는 기본적으로 상위 품목 한 개를 만드는 데 필요한 수량입니다.

ERP에서 상위 1,000개 기준 수량을 내보냈다면 `BOM_Base_Qty` 열에 `1000`을 넣습니다. 예를 들어 `Qty=2000`, `BOM_Base_Qty=1000`이면 한 개당 소요량은 `2`입니다.

이 열이 없으면 입력한 `Qty`를 그대로 사용합니다. 열을 추가했다면 모든 해당 행에 유효한 양수를 입력하세요.

## 결과를 읽기 전에

- 제외된 행이 있으면 원본과 행 번호를 확인합니다.
- 누락 단가가 있는 원가 합계는 완전한 원가로 해석하지 않습니다.
- 가정 수요나 누락 기간이 표시되면 실제 자료를 보완합니다.
- 대체품은 승인 상태와 단위, 다른 품목과 공유하는 재고를 확인합니다.
- 제안된 발주·일정 변경은 회사의 운영 조건과 승인 절차를 확인한 뒤 적용합니다.

PyBOM은 ERP에 자동으로 발주하거나 생산계획을 변경하지 않습니다.
