# PyBOM 1.0.0

The first packaged Windows release of PyBOM.

## Included

- Multi-level BOM analysis and cost rollup.
- Material requirements planning with dated receipts and suggested order actions.
- Inventory coverage, shortages, excess and clear-to-build analysis.
- Supplier follow-up, supply risk and what-if scenarios.
- Excel exports and an offline Manager Brief.
- Korean field guide and an example Excel workbook.

## Download

**[PyBOM-Windows-x64.zip](https://github.com/hey-yjenius/PyBOM/releases/download/v1.0.0/PyBOM-Windows-x64.zip)** is the application. Extract the whole ZIP and open `PyBOM/PyBOM.exe`.

No Python installation is required. Keep the `_internal` folder beside the executable.

Other release files:

- [PyBOM-Example-EN.xlsx](https://github.com/hey-yjenius/PyBOM/releases/download/v1.0.0/PyBOM-Example-EN.xlsx): English instructions, item descriptions and all 54 column notes; neutral fictional supplier labels.
- `PyBOM-Example.xlsx`: original Korean example workbook, also included in the Windows ZIP.
- `PyBOM-Source-1.0.0.zip`: application source and build instructions, without private development history.
- `SHA256SUMS.txt`: file hashes for verifying downloads.
- `PyBOM-Example-EN.xlsx.sha256`: checksum for the separately added English example.

GitHub's automatic **Source code (zip/tar.gz)** links contain this product-information repository, not the complete application source. Use `PyBOM-Source-1.0.0.zip` for the application source.

## Before you start

- Packaged for Windows x64; checked on Windows 11.
- Portable ZIP, not an installer.
- The executable is not code-signed.
- This release provides advisory analysis and does not update your ERP.

See [Getting started](https://github.com/hey-yjenius/PyBOM/blob/main/GETTING_STARTED.md) and [license information](https://github.com/hey-yjenius/PyBOM/blob/main/NOTICES.md).
